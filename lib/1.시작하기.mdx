## BDS 소개

BDS(Buzzle Design System)는 Material UI v6를 기반으로 확장된 디자인 시스템으로, Buzzle의 브랜드 아이덴티티를 일관되게 구현하기 위해 개발되었습니다. 이 프로젝트는 디자인 시스템 구축 경험을 공유하고, MUI 기반 컴포넌트를 확장하는 방법을 탐구하는 실험적 성격을 가지고 있습니다.

### 프로젝트 비전

BDS는 '화면에 글자가 없어도 이해할 수 있는 직관적인 UI'를 목표로 합니다. 시각적 요소와 상호작용 패턴을 통해 사용자가 자연스럽게 인터페이스를 이해하고 사용할 수 있도록 설계되었습니다.

## 디자인 시스템 아키텍처

BDS는 다음과 같은 계층 구조로 설계되었습니다:

1. **디자인 토큰**: 색상, 타이포그래피, 간격, 그림자 등의 기본 디자인 값
2. **기본 컴포넌트**: 버튼, 입력 필드, 텍스트 등의 기본 UI 요소
3. **복합 컴포넌트**: 기본 컴포넌트를 조합한 더 복잡한 UI 패턴
4. **페이지 템플릿**: 일반적인 페이지 레이아웃과 구조

이 구조는 MUI의 기본 철학을 따르면서도 Buzzle만의 고유한 디자인 언어를 구현할 수 있도록 설계되었습니다.

## 주요 특징

### 1. 확장된 MUI 컴포넌트

BDS는 MUI 컴포넌트를 기반으로 하되, Buzzle의 디자인 요구사항에 맞게 확장했습니다:

- **그라데이션 지원**: 텍스트와 버튼에 그라데이션 효과 적용
- **커스텀 애니메이션**: Motion 라이브러리를 활용한 부드러운 전환 효과
- **확장된 타이포그래피**: 더 다양한 텍스트 스타일 옵션

### 2. 디자인 토큰 시스템

BDS는 체계적인 디자인 토큰 시스템을 통해 일관된 디자인을 유지합니다:

- **색상 토큰**: 의미론적으로 구성된 색상 시스템
- **타이포그래피 토큰**: 일관된 텍스트 스타일
- **간격 및 크기 토큰**: 조화로운 레이아웃을 위한 값

### 3. 접근성 중심 설계

모든 사용자가 쉽게 사용할 수 있도록 접근성을 고려했습니다:

- **키보드 네비게이션**: 모든 상호작용 요소는 키보드로 접근 가능
- **스크린 리더 지원**: 적절한 ARIA 속성 적용
- **충분한 색상 대비**: WCAG 지침을 준수하는 색상 사용

## 시작하기

### 설치

```bash
# npm 사용
npm install @buzzle/bds @mui/material @emotion/react @emotion/styled

# yarn 사용
yarn add @buzzle/bds @mui/material @emotion/react @emotion/styled
```

### 피어 디펜던시 요구사항

```typescript
{
  "peerDependencies": {
    "react": "^17.0.0 || ^18.0.0",
    "@emotion/react": "^11.13.5",
    "@emotion/styled": "^11.13.5",
    "@mui/material": "^6.1.9",
    "motion": "^11.12.0"
  }
}
```

### 기본 사용법

```typescript
import { Button, Input, Text } from '@buzzle/bds';
import { CssBaseline } from '@mui/material';
import { ThemeProvider } from '@mui/material/styles';
import { bdsTheme } from '@buzzle/bds';

function App() {
  return (
    <ThemeProvider theme={bdsTheme}>
      <CssBaseline />
      <div>
        <Text variant="h1" gradient>환영합니다</Text>
        <Input
          label="이메일"
          placeholder="이메일을 입력해주세요"
        />
        <Button variant="contained">
          시작하기
        </Button>
      </div>
    </ThemeProvider>
  );
}
```

## 프로젝트 현황 및 로드맵

BDS는 현재 실험적 단계에 있으며, 다음과 같은 로드맵을 가지고 있습니다:

1. **기본 컴포넌트 완성**: 핵심 UI 요소 구현 (진행 중)
2. **테마 시스템 강화**: 다크/라이트 모드 및 커스텀 테마 지원
3. **접근성 개선**: 모든 컴포넌트의 접근성 검증 및 개선
4. **문서화 강화**: 상세한 사용 가이드 및 예제 추가
5. **성능 최적화**: 번들 크기 및 렌더링 성능 개선
